📖 DS Mart - Game Rules & Guide

📦 1. Trolley = Stack (LIFO)

Every product you pick up is pushed onto your shopping trolley using the C stack_push() function. The last item you took is at the top of the stack and can be removed first using stack_pop().

🔗 2. Inventory = Linked List (Dynamic Pointers)

Simultaneously, collected products are chained in a Singly Linked List in C with dynamic memory allocation (malloc). You can inspect memory addresses and search for products via pointer traversal.

👥 3. Billing Counter = Queue (FIFO)

Customers wait in line following First-In-First-Out. When billing, the cashier serves the customer at the front using C queue_dequeue(), while new customers join at the rear via enqueue().

🎯 4. Lives, Quizzes & Winning

Answer periodic Data Structures questions to earn score points (+25). Wrong answers cost 1 Life (❤️). Collect at least 4 products, solve the challenges, finish billing, and win the game!
